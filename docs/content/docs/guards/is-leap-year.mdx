## isLeapYear

Checks if a given year is a leap year according to the Gregorian calendar rules.

<Callout type="idea" title="Leap Year Rules">
- A year is a leap year if it is divisible by 4.
- However, years divisible by 100 are not leap years **unless** they are also divisible by 400.
- For example:

  - `2000`, `2020`, `2400` → leap years ✅
  - `1900`, `2100` → not leap years ❌
</Callout>

### Function Signature

```ts
function isLeapYear(year: Numeric): boolean;
```

### Parameters

- **`year`**: The year to check (can be number or numeric string)

### Returns

`true` if the year is a leap year, `false` otherwise

### Example Usage

```ts pg
import { isLeapYear } from 'chronos-date/guards';

console.log(isLeapYear(2000));  // true (divisible by 400)
console.log(isLeapYear(2020));  // true (divisible by 4 but not 100)
console.log(isLeapYear(1900));  // false (divisible by 100 but not 400)
console.log(isLeapYear("2024")); // true (accepts numeric strings)
```

### Notes

- Handles both numbers and numeric strings
- Follows Gregorian calendar rules
- Works with negative years (BC dates)
- Returns `false` for non-numeric inputs

### Type Definition

```ts
type Numeric = number | `${number}`;
```

### Key Points

- **Accurate** leap year detection
- **Flexible** input (numbers or numeric string)

## isDateLeapYear

Checks if a given date belongs to a leap year.

### Function Signature

```ts
function isDateLeapYear(date: Maybe<DateArgs>): boolean;
```

### Parameters

- **`date`**: The date to check. Can be `string`, `number` or `Date` object.

<Callout type="idea" title="Note">
For `undefined` date argument it uses the current date.
</Callout>

### Returns

`true` if the date belongs to a leap year, `false` otherwise.

<Callout type="idea" title="Note">
- Internally passes the date's year to [`isLeapYear`](#isleapyear) to check if the year is a leap year.
- Throws `TypeError` if the provided date is invalid (not parsable into a valid date by `DateConstructor`).
</Callout>

### Example Usage

```ts pg
import { isDateLeapYear } from 'chronos-date/guards';

console.log(isDateLeapYear(new Date()));      // true/false depends on current date
console.log(isDateLeapYear('2020-02-01'));    // true
console.log(isDateLeapYear('2021-02-01'));    // false
console.log(isDateLeapYear(undefined));       // true/false depends on current date
```

### Type Definition

```ts
type DateArgs = string | number | Date;
type Maybe<T> = T | undefined;
```

### Key Points

- **Accurate** leap year detection
- **Flexible** input (`numbers`, `string`, or `Date` object)
- **Convenient** for date-based checks
