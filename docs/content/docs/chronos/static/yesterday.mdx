## `yesterday()`

Returns a new `Chronos` instance representing yesterday's date.

### Signature

```ts
static yesterday(): Chronos
```

### Return Type

`Chronos` - Yesterday's date

### Example

```ts pg
import { Chronos } from 'chronos-date';

console.log(Chronos.yesterday()); 
```
