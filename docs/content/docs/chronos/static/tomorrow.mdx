## `tomorrow()`

Returns a new `Chronos` instance representing tomorrow's date.

### Signature

```ts
static tomorrow(): Chronos
```

### Return Type

`Chronos` - Tomorrow's date

### Example

```ts pg
import { Chronos } from 'chronos-date';

console.log(Chronos.tomorrow()); 
```
