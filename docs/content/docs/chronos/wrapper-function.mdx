## Overview

<Callout type="info" title="Info">
Function wrapper around the [`Chronos`](/docs/chronos) class that provides identical functionality with a simpler interface. All [`Chronos`](/docs/chronos) features are available through this function.
</Callout>

## Key Features

- Same functionality as `new Chronos()` but with function syntax
- Full access to all `Chronos` instance methods
- Inherits all static methods from `Chronos` class (`chronos` without call signature)
- Supports all `Chronos` input types
- Maintains identical type safety

### 🧩 Plugin System

[`Chronos`](/docs/chronos) supports a modular plugin system that allows you to extend its capabilities without bloating the core. Plugin methods are **not available by default**, you must explicitly register them using the `.use()` or `.register()` static method.

#### How it works

```ts pg
import { chronos } from "chronos-date";
import { seasonPlugin } from "chronos-date/plugins/seasonPlugin";

// Register the plugin before using its methods
chronos.use(seasonPlugin); 
// or
chronos.register(seasonPlugin);

console.log(chronos().season()); // ✅ Safe to use after plugin registration
```

<Callout type="info" title="Info">
Each plugin enhances the `Chronos` prototype and becomes available globally after registration.
</Callout>
## Usage

### Import

```ts
import { chronos } from "chronos-date";
```

### Basic Instantiation

```ts
// Function style
const date = chronos('2023-12-31')

date.year // 2023
date.formatSafe() // Formatted date string

// Class style (equivalent)
const date = new Chronos('2023-12-31')

date.year // 2023
date.formatSafe() // Formatted date string
```

### With Components

```ts
const date = chronos(2023, 12, 31, 15, 30)

date.year // 2023
date.formatSafe() // Formatted date string
```

## Available Methods & Properties

The wrapper provides access to all `Chronos` [**methods**](../chronos#available-methods) through the returned instance:

### Static Methods

All [`Chronos static methods`](/docs/chronos/static) are available directly on the wrapper function:

 | Method                                           | Short Description                                                  |
 | ------------------------------------------------ | ------------------------------------------------------------------ |
 | [now()](./static/now)                            | Returns the number of milliseconds since 1970-01-01 UTC.           |
 | [use()](./static/use)                            | Injects a plugin into the `Chronos` system.                        |
 | [register()](./static/register)                  | Alias for [`use()`](./static/use)                                  |
 | [utc()](./static/utc)                            | Creates a UTC-based `Chronos` instance.                            |
 | [with()](./static/with)                          | Creates a new instance with the provided time component(s).        |
 | [reconstruct](./static/reconstruct)              | Reconstructs a `Chronos` instance from a given value.              |
 | [parse()](./static/parse)                        | Parses a date string with a given format (limited support only).   |
 | [min()](./static/min)                            | Returns earliest `Chronos`.                                        |
 | [max()](./static/max)                            | Returns latest `Chronos`.                                          |
 | [clamp()](./static/clamp)                        | Restricts a date to a specified range                              |
 | [today()](./static/today)                        | Returns the current date in a specified format in local time.      |
 | [tomorrow()](./static/tomorrow)                  | Returns a new `Chronos` instance representing tomorrow's date.     |
 | [yesterday()](./static/yesterday)                | Returns a new `Chronos` instance representing yesterday's date.    |
 | [formatTimePart()](./static/format-time-part)    | Formats a time-only string into a formatted time string.           |
 | [getDatesForDay()](./static/get-dates-for-day)   | Returns ISO date strings for each occurrence of a weekday.         |
 | [isLeapYear()](./static/is-leap-year)            | Checks if the year in the date or year is a leap year.             |
 | [isValidChronos()](./static/is-valid-chronos)    | Checks if the given value is an instance of `Chronos`.             |
 | [isValidDate()](./static/is-valid-date)          | Checks if the given value is a valid `Date` object.                |
 | [isDateString()](./static/is-date-string)        | Checks if the given value is a valid date string.                  |
 | [isReconstructable](./static/is-reconstructable) | Checks if a value can be used to reconstruct a `Chronos` instance. |

#### Some Examples

```ts
import { chronos, Chronos } from "chronos-date";
import { timeZonePlugin } from "chronos-date/plugins/timeZonePlugin";

// Using wrapper function
chronos.parse('2023-12-31', 'YYYY-MM-DD');
chronos.today();
chronos.isLeapYear(2024);
// Registering a plugin
chronos.use(timeZonePlugin);

// Using class equivalent
Chronos.parse('2023-12-31', 'YYYY-MM-DD');
Chronos.today();
Chronos.isLeapYear(2024);
// Registering a plugin
Chronos.use(timeZonePlugin);
```
