## `isLastDayOfMonth()`

Checks if the current date is the last day of the month.

### Signature

```ts
isLastDayOfMonth(): boolean
```

### Return Type

`boolean` - Whether last day

### Example

```ts pg
import { Chronos } from 'chronos-date';

console.log({
    // Last day
    lastDay: new Chronos('2025-01-31').isLastDayOfMonth(), // true
    // Not last day
    notLastDay: new Chronos('2025-01-01').isLastDayOfMonth(), // false
});
```
