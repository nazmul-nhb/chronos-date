## `getTimeZoneOffsetMinutes()`

Returns the current `Chronos` instance's  offset in minutes.

### Signature

```ts
getTimeZoneOffsetMinutes(): number
```

### Return Type

`number` — The offset in minutes

### Description

Returns the **offset of the current `Chronos` instance's timezone in minutes**, based on the internally stored offset string (e.g., `UTC+06:00` → `360`).

- Independent of system timezone
- Matches the `±HH:mm` sign convention

<Callout type="info" title="Info">
Used internally for calculating UTC equivalence, especially when converting between time zones.
</Callout>

### Example

```ts pg
import { Chronos } from 'chronos-date';
import { timeZonePlugin } from 'chronos-date/plugins/timeZonePlugin';

Chronos.use(timeZonePlugin);

const base = new Chronos()

const tzOffset = base.timeZone('IST-India').getTimeZoneOffsetMinutes();

console.log({ 
    baseOffset: base.getTimeZoneOffsetMinutes(), 
    tzOffset 
});
```
