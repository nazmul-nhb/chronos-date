## `addDays()`

Adds days and returns a new immutable `Chronos` instance.

### Signature

```ts
addDays(days: number): Chronos
```

### Parameters

- `days`: Number of days to add

### Return Type

`Chronos` - New instance with added days

### Example

```ts pg
import { Chronos } from 'chronos-date';

const original = new Chronos('2025-01-31');
const added = original.addDays(1);

console.log({ original, added });
```

### Alternative

- You can also use [`add`](./add) method as `original.add(1, 'day')`.
