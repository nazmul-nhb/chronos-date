## `addMinutes()`

Adds minutes and returns a new immutable `Chronos` instance.

### Signature

```ts
addMinutes(minutes: number): Chronos
```

### Parameters

- `minutes`: Number of minutes to add

### Return Type

`Chronos` - New instance with added minutes

### Example

```ts pg
import { Chronos } from 'chronos-date';

const original = new Chronos('2025-01-31');
const added = original.addMinutes(1);

console.log({ original, added });
```

### Alternative

- You can also use [`add`](./add) method as `original.add(1, 'minute')`.
