## `addSeconds()`

Adds seconds and returns a new immutable `Chronos` instance.

### Signature

```ts
addSeconds(seconds: number): Chronos
```

### Parameters

- `seconds`: Number of seconds to add

### Return Type

`Chronos` - New instance with added seconds

### Example

```ts pg
import { Chronos } from 'chronos-date';

const original = new Chronos('2025-01-31');
const added = original.addSeconds(1);

console.log({ original, added });
```

### Alternative

- You can also use [`add`](./add) method as `original.add(1, 'second')`.
