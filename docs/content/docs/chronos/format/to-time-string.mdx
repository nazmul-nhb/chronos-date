## `toTimeString()`

Returns a string representation of the time portion of the date.

### Signature

```ts
toTimeString(): string
```

### Return Type

`string` - Time string

### Notes

- Returns localized string representation.
- Includes timezone information when an instance created with [`timeZone`](/docs/plugins/timezone-plugin#timezone) method.

<Callout type="info" title="Note">
It is different than native [`Date.prototype.toTimeString()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/toTimeString).
</Callout>

### Example

```ts pg
import { Chronos } from 'chronos-date';
import { timeZonePlugin } from 'chronos-date/plugins/timeZonePlugin';

Chronos.use(timeZonePlugin);

const date = new Chronos('2025-01-15');
console.log(date.toTimeString());
// "06:00:00 GMT+0600 (Bangladesh Standard Time)" --> Depends on system timezone

const kolkataTime = date.timeZone('Asia/Kolkata');
console.log(kolkataTime.toTimeString());
// "05:30:00 GMT+0530 (India Standard Time)" --> Timezone locked to Asia/Kolkata

const nycTime = date.timeZone('America/New_York');
console.log(nycTime.toTimeString());
// "19:00:00 GMT-0500 (Eastern Standard Time)" --> Timezone locked to America/New_York
```
