## `toString()`

Returns a string representation of the date and time.

### Signature

```ts
toString(): string
```

### Return Type

`string` - Date string

### Notes

- Returns localized string representation.
- Includes timezone information when an instance created with [`timeZone`](/docs/plugins/timezone-plugin#timezone) method.

<Callout type="info" title="Note">
It is different than native [`Date.prototype.toString()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/toString).
</Callout>

### Example

```ts pg
import { Chronos } from 'chronos-date';
import { timeZonePlugin } from 'chronos-date/plugins/timeZonePlugin';

Chronos.use(timeZonePlugin);

const date = new Chronos('2025-01-15');
console.log(date.toString());
// "Wed Jan 15 2025 06:00:00 GMT+0600 (Bangladesh Standard Time)" --> Depends on system timezone

const kolkataTime = date.timeZone('Asia/Kolkata');
console.log(kolkataTime.toString());
// "Wed Jan 15 2025 05:30:00 GMT+0530 (India Standard Time)" --> Timezone locked to Asia/Kolkata

const nycTime = date.timeZone('America/New_York');
console.log(nycTime.toString());
// "Tue Jan 14 2025 19:00:00 GMT-0500 (Eastern Standard Time)" --> Timezone locked to America/New_York
```
