## `toString()`

Returns a string representation of a date.

### Signature

```ts
toString(): string
```

### Return Type

`string` - Date string

### Notes

- Returns localized string representation.
- Includes timezone information when relevant.
- This method is the basis for the `String()` constructor and the `String.prototype.toString()` method when called with an object.

### Example

```ts pg
import { Chronos } from 'chronos-date';

const date = new Chronos('2025-01-15');
console.log(date.toString());
// "Sun Jan 15 2025 00:00:00 GMT-0500 (Eastern Standard Time)"
```
